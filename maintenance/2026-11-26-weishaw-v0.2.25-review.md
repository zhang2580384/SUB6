## Security and compatibility review

- No payment callback, signature-verification, recharge-credit, customer-balance write, migration, installer, or CI-workflow path was changed by this candidate. The account billing-rate sync remains opt-in. New group-name/notes sync requires both the upstream probe and group-sync settings and updates account display fields only; it does not write customer balances.
- The new group-preview endpoint is registered under the authenticated admin account routes. It sends a saved or explicitly entered API key to the configured upstream endpoint; the base URL passes the existing validator, redirects are disabled, and returned display text is validated before use. This outbound credential handoff is intentional and must only be used with a trusted configured endpoint.
- Header identity variables derive values from the authenticated API-key request context. Unsupported account/request contexts fail closed; client-supplied identity headers are not the source. The associated request-scope logging path redacts expanded values.
