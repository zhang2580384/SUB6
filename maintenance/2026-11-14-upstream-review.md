## 安全与行为审查

采用风险重点人工审查、静态差异清单和回归验证，不是全部行的穷尽审计。
在已审查范围未识别出具体恶意改动，不能据此或凭扫描结果证明不存在投毒。

支付回调、签名／重放校验、订单归属、充值入账、余额管理、金额与币种校验、
鉴权中间件本轮无改动。计费用量改动只附加请求时的平台快照；地区预算结算
保留分配所有权、API key 归属和原有金额字段。未新增运行依赖、锁文件、安装器、
更新下载目标或凭据外传目标；被排除的上游工作流不执行。

HTTP/2 peer reset 在真实传输边界形成受信错误标记，保留已发送的 HTTP 状态，
生成终止错误，阻止同一已提交请求自动重放；部分用量继续保留。用户错误视图
仅显示固定分类和允许的 reset reason，不透传账号、凭据或任意上游异常正文。
Ops、监控和 AIOps 的 SQL 统计纳入该失败并避免把部分输出重复记为成功。

OAuth 429 永久停调仍需账号明确启用、已持久化 owner、明确七天窗口、有效且
新鲜的使用率／时间戳、未过期 reset 和阈值条件。冲突或无效周数据会使旧证据
失效；五小时窗口和不相关的无效邻窗不会冒充周证据。未放宽人工调度开关。

新增 HTTP 400 丢弃旧加密历史重试是有上下文损失的 Beta 功能，默认关闭。
仅显式加密拒绝、同账号／凭据／路由、未暴露输出、会话及所有权验证通过时
允许一次受限恢复；不用于普通 400、传输中断、SSE 或跨账号重试。

管理员平台筛选经过允许值校验与 SQL 参数绑定，缓存键、列表、统计、图表和
导出一致。平台从请求时记录，旧记录保留 unknown，不用当前账号或分组反推。
平台筛选时禁用未支持该条件的清理／明细展开。账号运营选择器保留编辑草稿，
防止后台轮询和旧响应覆盖已保存内容。

SUB6 品牌、社区二维码、许可证与归属、低 token 探活、独立直连辅助服务、
管理员升级功能均保留。未恢复定制融合生图，上游图片桥接默认关闭。

## 迁移与升级建议

新增 `343_usage_log_platform_snapshot.sql`：对 usage_logs 增加可空 VARCHAR(50)
平台字段，无历史回填。新增 `344_usage_log_platform_index_notx.sql`：并发建立
`(platform, created_at DESC, id DESC)` 索引；中断遗留的无效索引会在重试前重建。
其余 419 个 SQL 迁移文件内容保持不变；既有迁移账本中的额外历史记录应保留，
不能直接用文件数替代现网迁移账本行数。

增加字段仍需短暂表锁，并发索引有 I/O、等待长事务和临时磁盘成本。隔离小库
通过不代表生产大表已完成容量或锁等待评估。启动会自动执行迁移，操作前需
明确执行窗口、锁与超时、磁盘余量、备份和应用回退方案。

本次改变迁移集合，现有托管升级器的同迁移集合门禁会拒绝直接从 0.1.4 滚动
升级。应暂留 0.1.4；完成单独迁移评估后再决定新二进制发行与生产升级。
不得绕过门禁或重打包旧 Release。添加的列和索引在隔离测试中兼容旧迁移
读取器；这不等同于已验收所有旧版业务回退。回退应保留账单和新增业务数据，
不能通过整库还原丢弃升级期间的交易。独立辅助服务仍需单独维护。
