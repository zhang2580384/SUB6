# SUB6 0.1.4 发行审查

本次继承 0.1.3 的 release 构建、SUB6 运行包兼容和可选托管滚动更新功能。
上游仍为 Ranxi 2.21.2，精确同步 ccf997c73868083d96c0bec56e71c1a34d26c98a，
没有重新合并上游。已发布的旧版本与资产保持不变。

修复调度缓存的发布顺序封装未透传可选就绪检查接口的问题：正常共享缓存不再
误报未就绪，缺少检查能力或检查失败时仍拒绝接入。新增通过真实服务构造函数
安装封装后的成功、错误透传和不支持检查回归。

修复托管控制器在私有 umask 077 下解包时生成 root 专用运行资源目录的问题。
显式设置运行子目录 0755、资源文件 0644、可执行文件 0755，外层构建目录保持
0700。新增 Linux 私有 umask 测试，覆盖显式目录和隐式嵌套父目录。控制器是
独立宿主机服务，已有安装须单独更新该脚本后再进行网页升级。

无 SQL 迁移、依赖、支付、计费、余额或图片融合变化。延续强制校验和、发行源码
对应、同迁移集合兼容门禁、未授权探针拒绝、旧请求排空和 WS 保留机制。
验证以对应公开提交 CI 为准，包括定向调度回归、Linux 控制器安全测试，以及
原有前后端、支付和隔离数据库检查。检查不代表不存在未知漏洞。

有新版时显示“立即更新”；最新版本显示“已是最新版本”。单 full 节点切换仍可能
使管理和登录短暂重连，不能承诺绝对零中断。详见 deploy/managed-updater/README.md。
