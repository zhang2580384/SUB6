# SUB6 0.1.3 发行审查

上游仍为 Ranxi 2.21.2，源码同步提交 ccf997c73868083d96c0bec56e71c1a34d26c98a；
发行提交 dbed7697aa56e76c6eb48c4914fa441496b67bdd。SUB6 使用独立版本号，
管理员版本信息继续展示上游版本和提交。此发行继承 0.1.2 的直连配置、登录验证
处理和已读提示修复，没有重新合并上游，也不包含已回退的图片融合功能。

恢复 release 构建标志及 SUB6 压缩包识别。管理员在有新版本时可使用“立即更新”。
新增可选 Unix socket 控制器，让多容器安装将更新、回滚、重启交给运维端执行，
页面显示进度并允许切换期间短暂重连；未配置控制器的安装保留现有行为。

没有修改 SQL 迁移、支付签名、订单金额、充值入账、计费或余额逻辑，没有新增
依赖。状态与操作 API 沿用管理员鉴权；主服务排空探针要求本地 token，未授权
返回 404。网页没有任意命令、下载 URL、主机路径或 Docker socket 权限。
控制器只接受本仓库最新稳定发行，校验包、tag 提交及兼容元数据，拒绝越界路径、
链接、特殊文件和超限包；root 复制应用配置不跟随应用拥有的符号链接。

验证范围：Go 更新服务/处理器/生命周期定向回归、前端类型检查/构建/版本组件
回归、控制器恶意包/路由/排空协议/启动失败及停止超时恢复测试。公开 CI 还运行
完整单元测试、独立支付引擎回归和隔离数据库迁移/队列集成测试。以相应发行提交
的 CI 结果为准；静态检查和测试不能证明无未知漏洞。

部署顺序、权限、迁移兼容边界和恢复说明见 deploy/managed-updater/README.md。
控制器不是通用集群编排器；安装前必须核对所有入口和真实容器模板。保留账单数据
及原配置，不自动恢复旧数据库。含 SQL 变更的未来版本必须另行审查。
