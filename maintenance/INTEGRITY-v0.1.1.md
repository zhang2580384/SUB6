# 独立完整性复核

以锁定 production 原始树 `ccf997c73868083d96c0bec56e71c1a34d26c98a`
为基准，逐文件对照 SUB6，并在私有证据中加入原应用基线形成三方清单。
清单记录每个文件的模式、Git blob、相同/覆盖/排除/新增状态；比较 Git 清理
后的 blob，避免将 Windows 工作树 CRLF 误判为源码更改。摘要见
upstream-tree-review.json；机器专属与历史私人证据不进入公开仓库。

## 发现并处理

1. 品牌批量替换误改了 Grok/Copilot 稳定协议头；已恢复原协议并保留 SUB6
   兼容别名，测试覆盖可信身份覆写和明确 opt-out 优先。
2. 插件 Go 字段品牌替换及独立语义版本可能破坏宿主兼容；恢复原字段/JSON
   协议，并用 Ranxi 基线匹配插件版本。独立更新器版本仍为 SUB6 0.1.1。
3. 新上游 VERSION 与 SUB6 VERSION 显式冲突；选择 0.1.1，同时添加正式版/
   精确同步提交展示。没有保留冲突标记，也没有整批静默选择某一侧。
4. 部署示例残留的 sub6:0.1.0 改为当前版本。旧安装器的失效关闭是有意行为；
   历史部署指南增加提示，不再将它们作为本发行的可执行安装入口。
5. 对历史额外迁移记录增加真实 PostgreSQL 回归：完整文件名相同才核验，
   未知记录保留，相同数字前缀的新文件独立执行，再次执行幂等。

## 逐类对照

- 后端未删除任何上游业务文件。Ent 生成模型、SQL 迁移、前后端现有 DTO/
  路由、Go 依赖锁和嵌套支付/SQLite 模块源码保留。新增版本元数据为可选
  扩展，原 version/current_version 字段保留。BEpusdt 唯一差异为测试连接清理。
- 检查全部运行时 Go 差异：发行标识/更新来源、显式 OAuth 客户端、去除
  不受控凭据接收端默认值、跨平台安全解包、Grok 低 token 探活、版本/
  迁移入口和上述协议修复。未发现意外整批漏合并或业务删除。
- Grok 冲突解决同时保留 monitorProbe 和新的原生 OAuth 证据；既有鉴权、
  回调签名/金额/所有权/幂等、余额、计费和管理路径未被替换为旧分支版本。
- 前端运行时差异除版本元数据外是品牌、社区图及更新/回滚来源；依赖锁
  保留。移除捐赠二维码与推广，社区图片两个路径复用核对过的同一 PNG。
- 保留 go.mod 的 gin/validator 兼容 replace 和本地 BEpusdt/SQLite replace，
  未只保留 mod 文件而漏掉实现。构建保留 docs/legal、web/dist、resources。
- 排除上游 188 个 .github 文件及旧 GoReleaser 入口：浮动 Actions、安装/
  发布权限和上游历史依赖不适合直接成为 SUB6 发布链，自有 CI 替代。
- 排除上游截图/伙伴图片/旧社区图片、历史运维记录、openspec 冻结 tar/patch、
  上游 CLA 和旧进度/执行报告；保留 LGPL、作者、上游出处、必要法律文档
  和第三方对应源码。排除不表示判定这些文件恶意。
- 可选 direct-access 为经过脱敏和鉴权加固的定制覆盖，保持独立部署。机器
  专属提权/边缘配置安装器不发布。定制生图分支继续排除。

## 验证

本地聚焦：主程序来源/插件宿主、版本缓存、插件兼容、Grok 头与低 token、
Copilot 身份覆写、支付回调相关回归；前端 store/sidebar/header 48 项、lint、
类型检查和构建通过。完整 Linux 单元、真实 PG/Redis 额度/租约/历史迁移
回归、支付模块及 sidecar 由本发行提交的固定只读 Actions 执行，最终状态
见该提交/Release 的 CI 链接，不把条件跳过记作已验证。

源码和每个公开可达提交/标签/对象需重新过敏感信息及资产门槛后才能推送。
自动扫描不证明没有缺陷；完整性清单也不替代生产副本和真实协议验收。
