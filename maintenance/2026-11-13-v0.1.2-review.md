人工复核本次全部改动：主程序后端仅更新发行版本；支付回调、签名、重放、
金额/币种、订单归属、入账与余额、主程序管理权限/鉴权没有新增业务改动。
sidecar 保留每次请求向主站验证身份/角色、Origin 检查、参数化 SQL、用户归属、
事务锁、名额边界、管理员调整审计、同步快照与超时关闭逻辑。数据库 schema
与依赖锁文件保持原样。新增管理配置接口仅可由主站验证的管理员读取，
不返回鉴权地址或数据库凭据，不提供修改接口。

配置中的鉴权地址由运维控制，必须是固定 `/api/v1/auth/me` 路径的 HTTPS
地址，或数字回环地址的 HTTP；拒绝凭据、查询参数、片段及非回环 HTTP。
鉴权请求保留证书校验、禁用环境代理并拒绝重定向，避免携带令牌跳转。
品牌文案经 Jinja 自动转义，浏览器表格继续使用 textContent。
CI 仍是固定 Actions 提交、contents:read、禁用检出凭据持久化；未添加部署、
插件下载、远程脚本执行、第三方二进制发布或写权限。本次 CI 仅增加配置测试
并更新构建版本。审查和扫描不构成“绝无恶意代码”的证明。

## 修复内容

- 独立直连服务不再依赖代码内置部署地址。支持运维 JSON 文件和环境覆盖，
  缺失必填配置时拒绝启动；提供通用品牌、页面文案及 systemd 示例。
  鉴权应指向稳定站点路由，避免容器替换后仍连接旧容器。
- 白名单刷新成功后清除旧的登录/同步错误，保留尚未提交的 IP 和备注。
- “新功能”提示改为 6px 红点，保留无障碍名称与焦点。设置标签内每项最多
  一个被动红点，点击红点区域仍进入标签；空间不足时标签横向滚动，保留文字。
- 成功加载并进入对应设置标签后即标记已读；侧栏按实际目标路由标记已读。
  未访问标签、其他账号、未来的新功能 ID 和显式新版本仍可提醒。
  保留原有浏览器存储键和旧已读记录，不因补丁升级批量重置。
- 通用设置增加独立白名单服务配置说明入口。客户名额管理与运维鉴权配置
  分开；网页不能修改鉴权回源。

## 兼容性、升级与回滚

从 0.1.1 升级没有新增主程序或 sidecar SQL 迁移，没有新增主程序配置项，
不改变余额、累计充值口径、人工名额覆盖或白名单记录。旧版融合生图没有恢复；
上游 Codex 图片桥接继续保持原有显式启用边界，默认关闭。

建议在完成发行验证后升级主程序以取得界面修复；独立 sidecar 需要另外更新
代码并显式核对四项必填配置。主程序二进制不包含独立 Python 服务，替换二进制
不会自动更新它。完整配置、权限和验收步骤见
[sidecar 指南](../deploy/direct-access/README.md)。Gunicorn HUP 可让新 worker
重读 JSON/代码，但不会重读 systemd EnvironmentFile；环境值变更需要受控重启
该独立服务。不能将仅编辑 env 后 HUP 误认为配置已生效。

保留 0.1.1 二进制、运行资源和 sidecar 代码/私有配置备份。0.1.2 的代码回滚
不需要删除 schema 或恢复业务数据；浏览器新增已读状态可由旧版兼容读取。
更早版本升级与数据库回滚的约束仍以
[0.1.1 兼容性说明](2026-11-13-v0.1.1-upgrade.md)为准。
生产切换和 sidecar 部署均需独立运维指示，公开 CI 不会执行。

## 验证与发布证据

验证包括前端完整测试、lint、类型检查和嵌入前端构建；侧栏/设置红点的
访问已读、重载持久化、账号/公告版本隔离、未完成/失败加载，以及白名单旧错误
恢复均有回归。sidecar 14 项测试在仅监听回环的一次性 `sub6_review` 库上运行，
包含权限、归属、名额、重定向与配置转义。另以虚构本地账号检查主题和窄屏。

本地最终受影响回归为 6 个文件、144 项通过，lint、vue-tsc 和 Vite 构建通过。
首次全量前端运行的 3 个失败断言依赖旧的手动关闭行为；调整为访问已读后，
其所在文件已全部通过，最终全量结果由 Linux CI 再确认。额外的 Windows
后端测试中 cmd/server、handler 通过；service 全量因 Python3 启动、代理拒绝
错误和 POSIX 文件权限/目录同步等平台假设失败，因此不将该运行计为通过，
保留 Linux CI 作为目标平台验证。本次没有为消除这些失败修改后端业务代码。

最终发布前从已提交 Git blob 导出，延续既有脱敏公开历史，核对文件内容及模式，
审计当前树和所有可达提交/标签/blob。私有集成历史和运维证据不进入发行仓库。
Linux amd64 二进制从最终公开提交构建并嵌入前端；提交、树、工具链和 SHA256
记入发行 `build-info.json` / `checksums.txt`。保留 LGPL、GPL 组件对应源码、
许可证和上游署名，不覆盖已有 0.1.0/0.1.1 标签或资产。

最终通过的 CI 和测试数量以本次 Release 说明为准；CI 结果仅验证测试范围，
实际部署仍需核对业务配置、入口与真实鉴权，不能据此自动升级生产。
